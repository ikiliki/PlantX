# PlantX skills

## Steps

1. Match the task to the index below.
2. Read only the matching skill files (paths, not pasted bodies).
3. Do the work.
4. If the task added or changed a repeating pattern, end with `plantx-skill-keeper`.

## Handing off to a subagent

Pass the skill **paths** in the brief. Do not paste skill text into the prompt.

| Skill | Path | When |
